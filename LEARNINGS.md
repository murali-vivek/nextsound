# AI-Assisted Development Learnings

After about three years as a software engineer, I've focused on one principle: leveraging AI as a productivity enhancer rather than a bypass that circumvents critical thinking.

While most tutorials on AI-powered development simply demonstrate features, I wanted to develop genuine expertise in this practice. I built a Spotify clone using Cursor, approaching it as a serious engineering endeavor rather than mindlessly accepting suggestions.

## My Approach

- Gained deep understanding of the codebase before making modifications (prioritizing Ask mode over Agent mode)
- Formulated and validated plans before writing any code
- Configured .cursorignore and .cursorindexingignore to manage Cursor's context awareness — discovering this is also crucial for protecting sensitive data from AI tools in production environments
- Crafted detailed prompts with clear boundaries (factoring in current tech stack, using visual input for interface issues)
- Maintained plan.md as an evolving specification for substantial features
- Scrutinized every AI-generated suggestion as carefully as I would review a colleague's pull request

## Key Insight

Artificial intelligence doesn't eliminate the necessity for engineering discernment — it actually elevates the standard, particularly regarding what information and files you allow it to access. Generating code from prompts is straightforward. The real work involves comprehending systems, mitigating risks, evaluating tradeoffs, and taking responsibility for what gets deployed.
